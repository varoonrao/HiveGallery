# Hive Gallery V1

Native Android gallery test build. Android 10+.

Upload app/, build.gradle, settings.gradle and gradle.properties to the repository root. Create .github/workflows/build-apk.yml with the supplied workflow. Run Build Hive V1 APK from the Actions tab. Download the HiveGallery-v1 artifact, extract the APK and install it on your Android phone.

This version is debug-signed and intended for personal testing. No OTA configuration, custom signing secrets, or Android Studio is required. A future release signed with a different key will require uninstalling this test version first. No device media is uploaded.
